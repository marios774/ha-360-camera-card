# Version 1.1

Version 1.1 is compatible with existing 1.0 YAML configurations.

## New options

```yaml
double_tap_home: true
named_presets:
  Garage:
    yaw: 48
    pitch: 47
    roll: 180
    fov: 82
```

The visual editor covers common stream, profile and view settings. Advanced calibration remains in YAML.
