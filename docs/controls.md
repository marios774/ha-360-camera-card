# Controls

The card must have keyboard focus before keyboard shortcuts work. Click once
inside the video.

| Key | Function |
|---|---|
| `↑` `↓` `←` `→` | Move view |
| `+` `-` | Zoom |
| `0` | Home |
| `i` | Copy YAML and show values |

Mouse/touch dragging changes the view. The mouse wheel changes zoom.
